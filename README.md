# Pet&Style 🐾

![Preview do Projeto](assets/pet&style.png)

Loja virtual fictícia desenvolvida como projeto acadêmico com o objetivo de praticar a criação de interfaces responsivas para e-commerce utilizando HTML, CSS e frameworks de estilização.

## 📋 Sobre o Projeto

O Pet&Style é um site de vendas de produtos para pets que apresenta uma página moderna e responsiva, contendo banner promocional, catálogo de produtos e navegação adaptada para diferentes tamanhos de tela.

O projeto foi desenvolvido com foco em organização visual, experiência do usuário e responsividade.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* Bootstrap
* Tailwind CSS

## ✨ Funcionalidades

* Layout responsivo
* Banner promocional
* Catálogo de produtos
* Menu de navegação
* Design adaptado para dispositivos móveis
